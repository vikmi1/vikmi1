# Python Developer · Backend, Telegram Bots, LLM Integrations

I build services and apps powered by AI — from prototype to a finished product with
documentation, tests and Docker deployment. My main language is Python, with Kotlin
for mobile. I integrate Claude and OpenAI, build RAG over documents, add speech
recognition, generate PDFs and store data in PostgreSQL and SQLite.

## Tech stack

| Area | Technologies |
|---|---|
| Languages | Python, Kotlin, SQL, HTML/CSS, JavaScript |
| Backend | FastAPI, Flask, Pydantic, Jinja2, REST API, WebSocket |
| AI / LLM | Anthropic Claude API, OpenAI API, Whisper, RAG (ChromaDB, embeddings), prompt engineering |
| Telegram bots | aiogram 3 (FSM), pyTelegramBotAPI |
| Data | PostgreSQL, SQLite |
| User interfaces | Android (Jetpack Compose), Tkinter, Rich (terminal) |
| Tools | Docker, docker-compose, Git, GitHub, pytest, WeasyPrint |
