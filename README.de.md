# Python-Entwickler · Backend, Telegram-Bots, LLM-Integrationen

Ich entwickle Dienste und Anwendungen mit KI – vom Prototyp bis zum fertigen Produkt
mit Dokumentation, Tests und Deployment in Docker. Meine Hauptsprache ist Python, für
Mobile nutze ich Kotlin. Ich binde Claude und OpenAI an, baue RAG über Dokumente,
integriere Spracherkennung, erzeuge PDFs und speichere Daten in PostgreSQL und SQLite.

## Tech-Stack

| Bereich | Technologien |
|---|---|
| Sprachen | Python, Kotlin, SQL, HTML/CSS, JavaScript |
| Backend | FastAPI, Flask, Pydantic, Jinja2, REST API, WebSocket |
| KI / LLM | Anthropic Claude API, OpenAI API, Whisper, RAG (ChromaDB, Embeddings), Prompt Engineering |
| Telegram-Bots | aiogram 3 (FSM), pyTelegramBotAPI |
| Daten | PostgreSQL, SQLite |
| Oberflächen | Android (Jetpack Compose), Tkinter, Rich (Terminal) |
| Werkzeuge | Docker, docker-compose, Git, GitHub, pytest, WeasyPrint |
